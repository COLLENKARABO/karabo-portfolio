Project Overview

Project Overview — Double-Storey Rental Development

Township backroom development optimized for rental income. Every stage photographed as engineering evidence, no image quality reduction, original proportions maintained.

Description

Construction of 4x Standard Room + Bachelor + Passage + Communal Toilet per floor, double-storey. Site ±9.00m x 22.40m. External 230mm brick, internal 110mm, surface bed 85mm wood float. Foundation 600mm strip footing 600mm deep. Windows 600x600, 1000x1000, 1200x1000. Doors 813x2032. IBR roofing with gutter & downpipes. Electrical DB board, lights, switches, sockets, TV point. Plumbing hot/cold water, waste 40mm/110mm, gully, inspection eye, sewer 110mm CE.

✓ SANS 10400 compliant
✓ 85mm THK surface bed wood float
✓ 600x300 foundation with 85mm surface bed
✓ Shape surrounding finish 1:100 away from building
